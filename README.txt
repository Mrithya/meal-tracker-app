Personal Meal Builder App

How to use:
1. Unzip the folder.
2. Open index.html in Chrome, Edge, Safari or Firefox.
3. Pick meal, food and quantity.
4. The app calculates calories, macros, selected micros and guidance.
5. Click Save Today to add a historical daily log.
6. Use Export CSV to back up your history.

Important:
The app stores data in your browser local storage. If you clear browser data, history can be lost.
Export CSV regularly.

This is a lightweight local app, not a cloud app.
